# 한성대 알고리즘 스터디 (hansungCF)

> 직접 개설하고 운영한 교내 알고리즘 스터디입니다.
> 백준 문제를 기반으로 매주 모여 풀이를 공유하고 코드 리뷰를 진행했습니다.

---

## 📌 운영 개요

| 항목 | 내용 |
|---|---|
| 기간 | 2024년 1학기 (Week 1 ~ Week 13) |
| 형태 | 주 1회 오프라인 모임 |
| 활동 | 주간 문제 풀이 → 코드 공유 → Editorial 작성 |

---

## 📚 주차별 학습 내용

| 주차 | 주제 |
|---|---|
| Week 1 | 알고리즘 개요, 시간복잡도, Big-O |
| Week 2 | 브루트포스, 재귀 호출, 완전 탐색 |
| Week 3 | 정렬 알고리즘 (버블, 선택, 삽입 등) |
| Week 4 | 스택 (Stack) |
| Week 5 | DFS / BFS |
| Week 6 | 다이나믹 프로그래밍 (DP) |
| Week 7 | 누적합 (Prefix Sum) |
| Week 8 | 그리디 알고리즘 |
| Week 9 | 분할 정복 |
| Week 10 | 다익스트라, 플로이드 워셜 |
| Week 11 | 우선순위 큐 |
| Week 12 | 비트마스킹 |
| Week 13 | 스위핑 알고리즘 |
